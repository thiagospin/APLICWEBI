Exercício: Diferença entre Margin e Padding

Observe o bloco abaixo. Ele possui margin e padding para você comparar os espaços.

Este texto está dentro da área de padding.
O espaço entre a borda azul e esta caixa amarela é o padding do bloco.

O espaço entre este bloco azul e os outros elementos da página é a margin.

Resumo didático:
Padding = espaço interno (da borda para dentro).
Margin = espaço externo (da borda para fora).
